IntelliDesk portfolio demo policy

Travel expense policy:

Security policy:
- API keys are located by a unique prefix and the secret is verified with BCrypt.
- Full API keys are shown only once at creation and are never stored in plaintext.

Reliability policy:
- Document and retrieval workers use guarded status transitions, leases, generations, and fence tokens.
- A stale worker cannot overwrite the current indexing generation.
